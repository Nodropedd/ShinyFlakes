Android

  • Android app Android 7.0 or newer, any phone or tablet
    .apk

Open the file on your phone. The first time, Android asks you to allow installs from your browser or files app. Tor and Monero come built in; Monero needs an ARM phone, which is nearly all of them. The file name carries its version, so an older download is never mistaken for it.

Windows

  • Installer Windows 10 and 11, 64-bit
    .exe
  • Portable The program on its own, nothing installed
    .exe

The program is not code-signed yet, so Windows shows "Windows protected your PC" the first time. Choose More info, then Run anyway.

Linux

  • AppImage Any 64-bit distro from 2022 on. Needs FUSE 2.
    .AppImage
  • Debian, Ubuntu, Mint, Pop!_OS Ubuntu 22.04+, Debian 12+, Mint 21+
    .deb
  • Fedora, openSUSE Fedora 36+, openSUSE Tumbleweed
    .rpm
  • Arch, Manjaro, EndeavourOS, CachyOS Uses the system's WebKitGTK, so it is small
    .pkg.tar.zst

Install the one for your distribution:

sudo apt install ./ShinyFlakes-linux-amd64.deb
sudo dnf install ./ShinyFlakes-linux-x86_64.rpm
sudo pacman -U ShinyFlakes-arch-x86_64.pkg.tar.zst

The AppImage needs FUSE 2 (fuse2 on Arch, libfuse2 on Ubuntu), or run it with --appimage-extract-and-run.

What it does

Stays on your device

The seed is sealed with AES-256-GCM under a key your system's credential store holds. Add a passphrase and opening it also needs something only you know. There is no account and no server.

Routes through Tor

Balance, price and history lookups otherwise show a server your IP beside your addresses. Turn on Tor and they see a Tor exit instead. On Android, Tor ships inside the app.

Monero, done properly

Monero's own wallet daemon runs alongside the app, and your keys go from memory straight into it over loopback. Nothing is written to a file or shown on screen.

Swaps without an account

Trade one coin for another through ChangeNOW. You send from your own wallet and the other coin comes back to your own address.

Asks again when it matters

An authenticator code, checked entirely offline, before showing the seed, before a large send, and on the first unlock after a long absence.

Clears itself if abandoned

If the wallet goes unopened for a period you choose, the device forgets it. The coins stay on their chains, and your seed phrase brings them back anywhere.

Verify your download (optional)

Every file has a fingerprint, its SHA-256. If a download was swapped or damaged on the way to you, the fingerprint changes. Security projects publish them because for a wallet a swapped download means stolen coins. To check, run the command for your system on the file you downloaded and compare the result with its line below. If it differs at all, do not install it.

    Linux

    sha256sum ShinyFlakes-linux-x86_64.AppImage

    Windows (PowerShell)

    Get-FileHash .\ShinyFlakes-windows-x64-setup.exe

    macOS or any Unix

    shasum -a 256 ShinyFlakes-android.apk

    All fingerprints in one file: SHA256SUMS.txt

    Questions

    Can I build my own wallet from this code?

    Yes, and you are welcome to. Two conditions: keep a visible ShinyFlakes credit in the app itself, and link back to this repository from wherever you publish it. Rename it, change it, ship it — just do not pass the work off as having come from nowhere.

    Why are swaps off in my own build?

    Swaps go through ChangeNOW, which needs a partner key. That key belongs to this project and is not in the repository, so a build you make yourself has every other feature and a disabled swap screen. Get your own key from ChangeNOW to turn it back on.

    Is my seed phrase ever sent anywhere?

    No. It is encrypted on your device with a key held by your system's credential store, and there is no account and no server to send it to. Balance and price lookups talk to public endpoints using your addresses only, and Tor hides your IP from those.

    Does the app update itself?

    No. It tells you when a newer version is out and opens this page. You download and install it yourself. An app that fetched and ran its own updates would hand anyone who took over the release account a way onto every user's machine.

    Mac or iPhone?

    No plans. Building for Apple devices requires Apple hardware, and shipping to iPhone requires their approval.
